# BeagleDock

Nome escolhido pelo usuário: **BeagleDock**. Mascote: beagle em um badge escuro com cantos arredondados e indicador verde, preservando a linguagem visual acolhedora do aplicativo.

Arquivo final: [beagledock-logo.png](../../public/brand/beagledock-logo.png). PNG com transparência exterior, usado pela interface, favicon e ícones dos pacotes. Criado com a ferramenta integrada **image_gen**, sem chamada à API pelo projeto.

Prompt final:

> Use case: logo-brand. Create one finished application icon for a developer toolkit named BeagleDock. The artwork is a friendly BEAGLE DOG HEAD, unmistakable long floppy ears, tricolor tan/caramel brown, cream-white muzzle and blaze, small black nose and kind relaxed eyes, slight three-quarter view looking right. Match a simple cute flat mascot app-logo style: bold clean rounded shapes, minimal details, no outlines or only subtle dark details, warm muted caramel palette. Head centered large on an almost-black charcoal rounded-square badge, generous rounded corners, tiny green status dot at upper right inside badge. This replaces a minimalist flat capybara mascot with a beagle while preserving the same cozy developer-cockpit visual language. Square composition, icon legible at 32 pixels, single icon only. Outside the rounded square badge is genuinely transparent; the interior badge stays dark charcoal. No text, letters, wordmark, mockup, shadows, 3D, watermark, border frame, collage or extra symbols.

Compatibilidade: o banco `~/.capyai/capyai.db`, o perfil Chromium e a identidade do cofre `capyai`, o appId `dev.capyai.desktop` e a API interna `capyAPI` são mantidos para preservar histórico, identificadores nativos e credenciais. Esses identificadores não definem o nome comercial. `BEAGLEDOCK_DATA_DIR` configura um diretório alternativo; `BLEAGLEDOCK_DATA_DIR` e `CAPYAI_DATA_DIR` permanecem compatíveis. O hook gerenciado `bleagledock-permissions` e suas variáveis de comunicação são identificadores internos preservados para não instalar dois hooks de aprovação. A pasta do checkout não é movida durante a renomeação.
