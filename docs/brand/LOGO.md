Name chosen by the user: **BeagleDock**. Mascot: a beagle on a dark badge with rounded corners and a green indicator, keeping the app's cozy visual language.

Final file: [beagledock-logo.png](../../public/brand/beagledock-logo.png). PNG with an outer transparency, used by the interface, favicon and package icons. Created with the built-in **image_gen** tool, without any API call by the project.
